# Vanguard Item Manager

This application is a custom inventory manager for the game Destiny. It allows players to efficiently manage their in-game items, equipment, and characters. The app provides a user-friendly interface to search, filter, and organize items across different characters and the vault.

## Features

- **Search Functionality**: Quickly search for items across all characters and the vault.
- **Refresh Button**: Easily refresh the inventory data with a single click.
- **Weapon Stats**: View detailed statistics for each weapon, including a progress bar for certain attributes.

## Components

### WeaponStat
Displays the name and value of a weapon's stat, with an optional progress bar.

### RefreshButton
A button that triggers a refresh of the inventory data, with a rotating animation while the refresh is in progress.

### SearchInput
An input field that allows users to search for items by name and view their details.
